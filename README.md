# Mira

Interpreted programming language written in Java.

---

## Requirements

- Java 21
- Maven

---

## Build

```bash
mvn package
```

Produces `target/mira-RELEASE.jar`.

---

## Usage

**Run a script:**

```bash
java -jar target/mira-RELEASE.jar path/to/script.mira
```

**Start the interactive REPL:**

```bash
java -jar target/mira-RELEASE.jar
```
